# USA Regional Sales Analysis

A tutorial-based Python EDA project using the committed processed `Sales_data(EDA Exported).csv`.
The notebook now runs from that export, with explicit unit-cost, revenue, profit and weighted-margin
definitions. It calculates monthly total revenue and actual average invoice value. No missing raw
workbook or personal absolute path is needed for the supported analysis path.

Python 3.12: install `requirements.txt`, open `Sales_Analysis .ipynb` from this directory and Run All.
The unavailable original workbook means the original source joins cannot be independently replayed.
Screenshots and the presentation remain; they do not supply an editable Power BI dashboard.
No fixed placeholder business findings or causal effects are claimed. This is supporting learning work.
